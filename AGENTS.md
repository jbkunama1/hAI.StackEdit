## Project Context
- **Repo**: jbkunama1/hAI.StackEdit (Self-hosted StackEdit with `benweet/stackedit:latest`)
- **Stack**: Docker Compose / Portainer Stack
- **Port mapping**: Host 3030 → Container 8080
- **Persistence**: Docker named volume `stackedit_data` → `/data`
- **Network**: External `highfishNetwork`
- **No OAuth**: `benweet/stackedit` image has no documented env vars for self-hosted Google/GitHub OAuth

## Conventions
- Branch naming: kebab-case, prefixed by `jbkunama1-`
- Commits: Conventional commits (`feat:`, `fix:`, `chore:`, `docs:`)
- Secrets: Never commit — use `.env` (from `.env.example`) and GitHub Actions secrets
- CI: 4 workflows (trufflehog daily, security on PR/push, space-shooter weekly, testdriver on PR)

## Key Decisions (from backfill)
1. **Image choice**: `benweet/stackedit:latest` kept intentionally — matches existing running setup; OAuth self-host would require different image
2. **Persistence**: Docker volume `stackedit_data` (survives `compose down/up`); backup via `busybox tar`
3. **Security**: Triple secret scan (Gitleaks, TruffleHog, Trivy) + CodeQL SAST on every PR/push
4. **game.gif**: Auto-generated by `gh-space-shooter` Action, committed weekly
5. **No custom Dockerfile**: Direct image reference; no build step
