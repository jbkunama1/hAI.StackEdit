Highfish StackEdit Workspace

Selbst gehosteter Markdown-Workspace auf Basis von StackEdit und Docker.

Über das Projekt

Dieses Projekt stellt eine minimale, aber praxistaugliche Umgebung für StackEdit bereit. Die Kernidee: Du startest einen Container mit Docker Compose, erreichst StackEdit über deinen Browser und synchronisierst deine Notizen mit Diensten wie Google Drive oder GitHub.

Schnellstart

  1. Repo klonen und ins Verzeichnis wechseln.
  2. .env.example nach .env kopieren und bei Bedarf anpassen.
  3. docker compose up -d ausführen.
  4. Im Browser http://<dein-server>:3030 öffnen.

Cloud-Integration

StackEdit kann Dateien mit Google Drive, Dropbox und GitHub synchronisieren. Die Konfiguration der OAuth-Verknüpfungen erfolgt vollständig in der StackEdit-Oberfläche.
