Highfish StackEdit Workspace (OAuth)

Selbst gehosteter Markdown-Editor mit eigener OAuth-Konfiguration für Google Drive und GitHub.

Über dieses Setup

Dieses Projekt stellt eine StackEdit-Instanz bereit, die über eigene OAuth-Credentials mit Google Drive und GitHub kommunizieren kann. Damit kannst du deine Notizen unter deiner eigenen Domain betreiben und trotzdem Cloud-Synchronisation nutzen.

Schnellstart

  1. Repo klonen und ins Verzeichnis wechseln.
  2. .env.example nach .env kopieren und OAuth-Werte eintragen.
  3. Externes Docker-Netzwerk anlegen (falls nötig).
  4. docker compose up -d ausführen.
  5. Domain/Subdomain über Cloudflare/Tunnel auf den Host-Port leiten.
  6. StackEdit im Browser öffnen und Cloud-Workspaces einrichten.

Cloud-Integration

Mit korrekt gesetzten Umgebungsvariablen kann StackEdit deine eigenen OAuth-Clients für Google und GitHub nutzen. Die eigentliche Verknüpfung (Workspaces, Publish-Targets) erfolgt wie gewohnt in der StackEdit-Oberfläche.
