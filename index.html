Highfish StackEdit Workspace (benweet-original)

Selbst gehosteter Markdown-Editor auf Basis deines bestehenden `benweet/stackedit:latest`-Setups.

Über dieses Setup

Dieses Projekt bildet dein aktuelles StackEdit-Setup mit dem offiziellen Image `benweet/stackedit:latest` nach. Es eignet sich für Compose- oder Portainer-Deployment und bleibt absichtlich nah an deiner bisherigen laufenden Konfiguration.

Portainer-Deployment

  1. In Portainer Stacks öffnen und Add stack wählen.
  2. Den Compose-Inhalt aus docker-compose.yml in den Web Editor einfügen.
  3. Optional Variablen wie Port oder Container-Name im UI anpassen.
  4. Externes Netzwerk vorher anlegen.
  5. Stack deployen.

Wichtiger Hinweis

Diese Variante bleibt bewusst beim ursprünglichen Image und ergänzt keine spezielle OAuth-Self-Host-Konfiguration für Google Drive oder GitHub. Sie dient als saubere Repo-Version deines aktuellen, funktionierenden Basis-Setups.
