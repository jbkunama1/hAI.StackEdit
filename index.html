Highfish StackEdit Workspace (OAuth)

Selbst gehosteter Markdown-Editor mit eigener OAuth-Konfiguration für Google Drive und GitHub.

Über dieses Setup

Dieses Projekt stellt eine StackEdit-Instanz bereit, die über eigene OAuth-Credentials mit Google Drive und GitHub kommunizieren kann. Du kannst das Setup wahlweise klassisch mit Docker Compose oder direkt als Portainer Stack deployen.

Portainer-Deployment

  1. In Portainer Stacks öffnen und Add stack wählen.
  2. Den Compose-Inhalt aus docker-compose.yml in den Web Editor einfügen.
  3. OAuth-Variablen im UI setzen.
  4. Externes Netzwerk vorher anlegen.
  5. Stack deployen und Domain/Tunnel auf den Host-Port zeigen lassen.

Cloud-Integration

Mit korrekt gesetzten Umgebungsvariablen kann StackEdit deine eigenen OAuth-Clients für Google und GitHub nutzen. Die eigentliche Verknüpfung (Workspaces, Publish-Targets) erfolgt anschließend in der StackEdit-Oberfläche.
